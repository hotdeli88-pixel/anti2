# 교육부 공시 원문 라이선스 안내

본 저장소의 `data/processed/*.jsonl` 에 포함된 성취기준·성취수준·기재요령 텍스트는
대한민국 **교육부 고시 제2022-33호** 「2022 개정 교육과정」 별책 1~15 및
한국교육과정평가원(KICE) 연구보고서를 정본으로 한다.

## 적용 라이선스

- **공공누리 제1유형 (출처표시)** 적용을 가정한다.
- 각 JSONL row 의 `source.license` 필드에 실제 라이선스 식별자를 기록한다.
- 재배포 시 출처를 다음과 같이 표기한다:

> 출처: 교육부 고시 제2022-33호 「2022 개정 교육과정 별책 [N] - [과목명]」
> (대한민국 교육부, 2022년 12월 22일)

## 운영 책임

- 원문이 공공누리 제2~4유형(상업 이용 제한 등)으로 변경된 경우 즉시
  해당 데이터를 비활성화(`active=false`) 처리하고 별도 라이선스 협의에 들어간다.
- KICE 연구보고서·시도교육청 가공자료를 참고용으로만 활용하고 1차 정본은
  교육부 고시·NCIC 게시 본문에서 조달한다.

## 출처 검증

각 마이그레이션(`alembic/versions/0008_..0044`)는 다음을 보장한다:

- `achievement_standards.source_doc` 에 별책 식별자 기재 (예: `교육부고시 2022-33 별책8 중학교 수학`).
- `achievement_standards.source_json` 에 다운로드 시점·SHA256·URL 보존.
- `data/raw/manifest.json` 에 SHA256 일치 여부를 CI에서 검증.
